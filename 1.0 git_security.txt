dependabot. This checks for any vulnerabilities in files like ex-pom.xml. It will monitor files like npm related packages, docker related packages. It will look at vulnerabilities database A database which has all vulnerabilities in the world. And if finds a package that is vulnerable it will automatically create pull request and merge the PR. Within minutes a vulnerabilities is disclosed in the world. It will update the version in our repository so that we are safe from vulnerability.
It is very useful when we are working with multiple applications.

What it will do?
It will look for our yml file,pom.xml or npm file and it will compare the version with vulnerability database. If our version is vulnerable automatically it creates a pull request and update our go.mod file. It can also merge the file for us so that by the time we realize depandabot already fixes the issue.
